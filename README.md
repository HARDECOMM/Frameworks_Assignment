# Frameworks Assignment

## Overview
This project analyzes COVID-19 vaccination data using Python. It demonstrates data processing and visualization using streamlit frameworks.

## Features
- Data loading and cleaning
- Data analysis (e.g., vaccination rates by country)
- Visualization of results
- Simple web interface (if using Streamlit or Flask)

## Frameworks & Libraries Used
- **Python 3.x**
- **pandas**: Data manipulation
- **matplotlib**/**seaborn**: Data visualization
- **Streamlit** or **Flask**: Web app framework (choose based on your implementation)

## Setup Instructions

### 1. Clone the repository
```powershell
git clone <repo-url>
cd framework_assignment
```

### 2. Create and activate a virtual environment
```powershell
python -m venv myenv
myenv\Scripts\activate
```

### 3. Install dependencies
```powershell
pip install -r requirements.txt
```

### 4. Run the application
- If using **Streamlit**:
  ```powershell
  streamlit run app.py
  ```

## Usage Example
- Open the app in your browser (Streamlit will provide a local URL)
- Upload or use the provided `country_vaccinations.csv` file
- View analysis and visualizations
